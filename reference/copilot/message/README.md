# Message specs (align with VS Code Copilot Chat)

This folder documents **message formatting + UI behaviors** to align Tripilot's chat experience with **Copilot Chat in Visual Studio Code**.

Scope:

- Chat conversation rendering (user/assistant turns)
- Tool invocations and approval UI
- Edits review / pending changes UX
- Todo list / planning UX
- Layout + streaming + checkpoints + “thinking” presentation

Non-goals:

- Implementing the tools themselves (see ../built-in-tools)
- Using Copilot private/internal commands or APIs
