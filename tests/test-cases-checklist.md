# Tripilot 测试用例勾选清单

## A. 单元测试（Unit）

- [ ] SSE 事件单条解析
- [ ] SSE 多 data 行拼接
- [ ] SSE chunk 边界解析
- [ ] 回放排序稳定性（同 seq 场景）
- [ ] 场景映射键稳定性

## B. 集成测试（Integration）

- [ ] 回放态加载与实时态隔离
- [ ] Scene ↔ Timeline 双向定位
- [ ] approval request/resolved 状态联动
- [ ] failed 事件默认可见且不丢失

## C. 系统测试（System/E2E）

- [ ] 扩展启动与侧栏加载
- [ ] 新会话发送->工具调用->结果渲染闭环
- [ ] 回放列表加载->播放->停止->恢复

## D. 专项测试

### 性能
- [ ] 高频事件（>=1000）渲染耗时在阈值内
- [ ] 内存占用无持续泄漏趋势

### 安全
- [ ] 敏感路径编辑必须触发审批
- [ ] Token/secret 不落日志

### 可靠性
- [ ] 网络中断可恢复
- [ ] 解析异常不导致主流程崩溃

## E. 验收测试（Alpha/Beta）

- [ ] Alpha：内部用户场景走查通过
- [ ] Beta：目标用户灰度反馈通过
- [ ] 回归：关键链路全绿后允许发布
